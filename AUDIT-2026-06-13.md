### Findings — Pass 1

**Live (browser-observed):**
- **F1 · P2 · HACCP console error** — `GET /api/v1/aziende/{id}/haccp/config` → **404**, surfaces as a browser console error. Page renders a correct empty state, but the 404 leaks to console. Root cause shared with F7 below.
- **F2 · P2 · Edit-azienda form is incomplete** — `/aziende/[id]/edit` is missing Forma Giuridica, Codice Fiscale, CAP (legale+operativa), Provincia (legale+operativa), all Contatti (PEC/email/telefono/sito), admin data. These can be set at creation but NOT edited afterward. NOT data loss (verified — backend preserves omitted fields), but you cannot correct these fields via UI. File: `frontend/src/app/(dashboard)/aziende/[id]/edit/page.tsx`.
- **F3 · P3 · MMC `/calculate/niosh` ERR_ABORTED** — benign AbortController debounce-cancel of live recalculation; no console error, handled gracefully. No action needed (confirm not a re-render storm).

**Code audit — frontend agent (cold-start / save robustness is the through-line):**
- **F4 · P0 · Incendio save = delete-all-then-recreate, no transaction** — `assessments/incendio/[aziendaId]/page.tsx:181-211`. A POST failure (e.g. Render cold-start 502) after the DELETE loop permanently loses areas. Fix: POST-all-first then delete-old, or check `res.ok` and abort before destroying.
- **F5 · P0 · Stress finalize reads localStorage only** — `assessments/stress/[aziendaId]/page.tsx:592-606`. If localStorage write was blocked (incognito/full), finalize PUTs an empty `{}` over a real assessment. Fix: PUT from React state, not localStorage.
- **F6 · P1 · Gestanti duplicate POST** — `gestanti/[aziendaId]/page.tsx:~359`. Save before the create-vs-update cross-ref resolves → duplicate record. Fix: disable Save until resolved, or backend upsert by persona_id.
- **F7 · P1 · HACCP "any error = 404 → blank form → Save wipes config"** — `haccp/[aziendaId]/page.tsx:~163-203`. Config-fetch catch treats a cold-start 5xx the same as a real 404, blanks fields; a subsequent Save PUTs a wiped config. (Also the source of F1's console error.) Fix: inspect status; only blank on genuine 404, else show error + block Save.
- **F8 · P1 · POS chip selections persist on onBlur only** — `pos/[aziendaId]/page.tsx`. Role/phase toggles lost if user saves/navigates before blur; matrix save timer has no unmount cleanup. Fix: persist on toggle; clear timer on unmount.
- **F9 · P1 · MMC unchecked surplus-row DELETEs** — `mmc/[aziendaId]/page.tsx:~453-458`. Failed deletes leave orphan rows while UI reports success. Fix: check `res.ok || 204`.
- **F10 · P2 · No cold-start retry on assessment initial loads** — mmc/biologico/gestanti/incendio/microclima/pee/stress. A single 502/503 sets a permanent error (often no retry button). Only `PericoliPanel` + wizard handle this. Fix: reuse `PericoliPanel.fetchWithRetry`.
- **F11 · P2 · Microclima `refetchSaved` unhandled rejection** — `microclima/[aziendaId]/page.tsx:~40-65`. No catch on refetch → unhandled rejection + stale list.
- **F12 · P2 · PericoliPanel + POS debounce timer not cleared on unmount** — setState-after-unmount warning + wasted request.
- **F13 · P2 · Mutable-key focus loss** — HACCP CCP "Codice" field (`haccp:649-653`) and PEE telefono (`pee:~562`) keyed by editable value → row remounts each keystroke, input loses focus. Fix: stable synthetic key (same fix already applied to ambienti).
- **F14 · P2 · Gestanti "Annulla modifiche" doesn't revert** — only clears dirty flag, edited text remains. Fix: re-hydrate from last-saved snapshot.

**Code audit — backend agent (codebase is well-defended; reasoning-effort vocab confirmed CLEAN):**
- **F15 · P2 · `documents.py:663` `scalar_one()` can 500** — if the parent azienda was deleted, `open_document_for_editing` raises `NoResultFound` → 500 instead of 404. Fix: `scalar_one_or_none()` + raise NotFoundError.
- **F16 · P2 · `document_tasks.py:148-154` doc stuck `in_progress` forever** — if the rollback `commit()` itself fails (broken connection / soft-timeout mid-commit), status never resets, no UI recovery. Fix: wrap rollback in own try/except on fresh session + add stale-row sweeper.
- **F17 · P3 · `document_tasks.py:165` hard `time_limit=660` SIGKILL** — bypasses except handler, strands status at `in_progress`. Same sweeper fix.
- **F18 · P3 · `dependencies.py:27` `uuid.UUID(user_id)` ValueError → 500** — malformed-but-signed JWT sub. Fix: try/except → 401.
- **F19 · P3 · `persone.py:101,142` `assert reloaded is not None`** — stripped under `python -O`; replace with explicit NotFoundError.
- **F20 · SECURITY (P1) · `auth.py:38` `/auth/register` is ungated** — any visitor can self-register and becomes `role="admin"` of a brand-new org. Backend agent flagged "confirm intended." For a client B2B tool this is likely NOT intended — needs review (invite-only? disable public register?).
- Note: `main.py:11` CORS defaults to localhost — prod origins must come from env (verify).
